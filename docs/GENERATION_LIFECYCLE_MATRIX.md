## Rejected invariants

- More than one queued/running whole-book run is rejected by both application admission and a partial unique database index.
- Completion without the exact `Book.activeRunId` mirror rolls back rather than leaving a terminal run beside a stuck Book.
- A stale delivery token/fence cannot heartbeat, update workflow state, publish, or undo deletion.
- A failed/cancelled run cannot replace `publishedRunId`, published PDF namespace/fence, or published page-image set.
- Partial publication pointers and incompatible input/fingerprint reuse are rejected.
- Retry is limited to failed/cancelled workflow contracts; complete books use regeneration.
- Home mode skips generation debit/refund but does not bypass auth, ownership, quote confirmation, concurrency, provider, or hard-budget checks.

Evidence: 93 passing database integration tests cover fencing, cancellation, credit charging, outbox/redelivery, publication, page images, and deletion; unit suites cover recovery, snapshot normalization, artifact validation, and fingerprint compatibility.
